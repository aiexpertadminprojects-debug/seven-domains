SEVEN DOMAINS — PHASE 1 ADD-ON

This package adds standalone Phase 1 pages without replacing or deleting any existing website files.

UPLOAD
1. Extract this ZIP.
2. Upload the included HTML files into the repository root (same level as index.html).
3. Upload assets/phase1-pages.css into your existing assets/ folder. Do not overwrite styles.css or app.js.
4. Add the navigation links shown below to the existing header/footer in index.html.
